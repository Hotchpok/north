# 🔐 Password Manager Bot

Telegram-бот для безопасного управления паролями с шифрованием и напоминаниями.

## 📋 Возможности

- 🔐 **Генерация безопасных паролей** с настраиваемыми параметрами
- 🔒 **Шифрованное хранение** паролей в локальной базе данных
- 📋 **Управление паролями** для различных сервисов
- 🔔 **Ежегодные напоминания** о смене паролей
- ⚙️ **Настройка параметров** генерации паролей
- 🔑 **Мастер-пароль** для защиты доступа
- 💻 **Локальное хранение** данных на вашем устройстве

## 🛠️ Установка и настройка

### Предварительные требования

- Python 3.8 или выше
- Аккаунт Telegram
- Токен бота от [@BotFather](https://t.me/BotFather)

### Установка

1. **Клонирование репозитория:**
```bash
git clone <repository-url>
cd password-manager-bot
```

2. **Установка зависимостей:**
```bash
pip install -r requirements.txt
```

3. **Настройка бота:**
   - Создайте бота через [@BotFather](https://t.me/BotFather)
   - Получите токен бота
   - (Опционально) Настройте переменную окружения:
   ```bash
   export BOT_TOKEN='ваш_токен_бота'
   ```
   Или отредактируйте `config.py`:
   ```python
   BOT_TOKEN = 'ваш_токен_бота'
   ```

4. **Запуск бота:**
```bash
python main.py
```

## 🚀 Использование

### Основные команды

- **/start** - Начало работы с ботом
- **/help** - Справка по командам
- **/setmaster** - Установить мастер-пароль
- **/generate** - Быстрая генерация пароля
- **/generate_dialog** - Генерация и сохранение пароля
- **/list** - Показать все сохраненные пароли
- **/delete** - Удалить пароль
- **/settings** - Показать текущие настройки
- **/settings_dialog** - Изменить настройки генерации

### Примеры использования

1. **Установка мастер-пароля:**
   ```
   /setmaster MyStrongPassword123
   ```

2. **Быстрая генерация пароля:**
   ```
   /generate
   ```

3. **Сохранение пароля для сервиса:**
   ```
   /generate_dialog
   ```

4. **Просмотр всех паролей:**
   ```
   /list
   ```

5. **Изменение настроек генерации:**
   ```
   /settings_dialog
   ```

## 🔒 Безопасность

### Особенности безопасности
- **Локальное хранение:** Все данные хранятся на вашем устройстве
- **Шифрование:** Пароли шифруются перед сохранением
- **Мастер-пароль:** Доступ защищен мастер-паролем
- **PBKDF2:** Используется для хеширования паролей
- **Соль:** Уникальная соль для каждого пользователя

### Алгоритмы шифрования
- **Хранение паролей:** PBKDF2-HMAC-SHA256 с 100,000 итерациями
- **Шифрование данных:** XOR с ключом, сгенерированным из мастер-пароля

## 📊 База данных

База данных SQLite (`password_manager.db`) содержит следующие таблицы:

- **users** - Пользователи и мастер-пароли
- **password_settings** - Настройки генерации паролей
- **passwords** - Зашифрованные пароли
- **reminders** - Напоминания о смене паролей

## ⚠️ Важные предупреждения

1. **Резервное копирование:** Регулярно делайте резервные копии базы данных
2. **Безопасность устройства:** Обеспечьте физическую безопасность устройства с базой данных
3. **Мастер-пароль:** Не забывайте мастер-пароль - его невозможно восстановить
4. **Обновления:** Регулярно обновляйте зависимости для безопасности
5. **Доверие:** Используйте бота только с доверенными сервисами

## 🐛 Отладка и логирование

Логи сохраняются с уровнем INFO и выше. Для включения детального логирования измените `LOG_CONFIG` в `config.py`:

```python
LOG_CONFIG = {
    'format': '%(asctime)s - %(name)s - %(levelname)s - %(message)s',
    'level': 'DEBUG'  # Измените на DEBUG для детальных логов
}
```
